# PureFusion IPTV Plugin SDK

Use this reference to build and package an Android TV plugin independently of the closed-source PureFusionIPTV app. The [SDK repository](https://github.com/Eliminater74/PurefusionIPTV-plugin-api) provides public Kotlin contracts, a starter, packaging and developer signing. Core owns executable admission, the TV UI, playback and permissions. The Marketplace owns review and distribution.

The current SDK and host compatibility floor are both **Plugin API 3**. The SDK library builds for Android API 25+. The isolated runtime and starter require Android API 26+ and a host that implements the selected protocol. Public third-party executable distribution is gated, and arbitrary third-party screen IDs need a host launch integration.
