## Publish the pages

1. In the SDK repository's GitHub settings, enable Wikis if the Wiki tab is absent. Open the Wiki tab and initialize its Home page if needed. Follow [GitHub's Wiki editing instructions](https://docs.github.com/en/communities/documenting-your-project-with-wikis/adding-or-editing-wiki-pages).
2. Review the existing pages for topic matches. Update matching pages in place. Use the mapped filenames in a local Wiki repository, or paste each file's Markdown into the corresponding GitHub Wiki page. Use the mapped page titles and slugs, or adjust inbound links if you retain a different existing slug. The Home page supplies the navigation.
3. Publish the SDK documentation to its own repository before the Wiki so links back to `main` can resolve. Publish only the 14 mapped page files to the Wiki. This index belongs in the SDK repository.
4. Open Wiki Home and follow the navigation and source links. Check the README's live Wiki link after the Home page is visible.
