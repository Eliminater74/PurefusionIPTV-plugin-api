# Submission worksheet (outside listing v1)

This human worksheet is not uploaded JSON and contains no backend-controlled state.

- Publisher: Your Developer Name
- Developer ID/namespace: obtain from verified portal profile
- Developer website: your public website
- HTTPS support page: listing.support.url (include contact email on that page)
- Privacy policy URL when collecting/transmitting data: link/explain in fullDescription or support page
- Permissions rationale: explain every capability in fullDescription/review disclosure
- Rights/licensing disclosure: separate portal field, max 1,500 characters; document content/data/artwork/library rights
- Release notes: listing.changelog; required on updates
- Compatibility: API 3, Android API 26+, host with experimental surface/broker support
- Review notes: provide through authorized workflow when requested

Never add keys/passwords/tokens, private account UID, approval state or fabricated verification. Publisher is a display label; authorization comes from the signed-in server workflow.
